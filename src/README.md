Dice Roller Game 🎲

A simple Java console application that simulates rolling one or more dice using random numbers and ASCII art.

Features
* Roll multiple dice at once
* Random dice values from 1–6
* ASCII art display for each die
* Calculates the total of all rolls
* Input validation for number of dice

Technologies Used
* Java 
* Scanner 
* Random 
* switch expressions 
* Methods

How It Works
1) User enters how many dice they want to roll. 
2) The program generates random numbers between 1 and 6. 
3) Each dice face is displayed using ASCII art. 
4) The total value of all dice is shown at the end.
